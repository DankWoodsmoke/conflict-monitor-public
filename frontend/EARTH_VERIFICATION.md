## What changed and why

The old spatial views used correct longitude/latitude argument order but froze report entities after their first creation, invented 10,000 m aircraft altitudes for null/zero values, failed to refresh vessel heading/details, distorted orbital heights and disabled depth testing. Google mode also hid the globe, so a primitive-only depth fix could not guarantee horizon occlusion.

Earth is now the single persistent spatial canvas. Earlier `view=map` and `view=3d` bookmarks resolve to Earth. Media and Brief are auxiliary panels; closing them preserves the Earth camera and sources. The report feed, source/time filters, location selection, local coordinate/place search, camera controls, optional reference layers and replay are available within that workspace. Active orbital rendering, polling, counts and cosmetic sensor-like shader effects were removed.

Every retained entity ID refreshes its position, heading, label and source details. Coordinates must be finite and within geographic bounds; unresolved coordinates remain unplotted. Aircraft and vessels are explicit surface projections. Aircraft reported altitude and its provider reference remain metadata; no barometric/geoid/ellipsoid conversion or missing height is invented. Search camera distance follows declared report location precision rather than pretending that a country-level report is site precise.

All marker depth tests remain enabled. An independent WGS84 ray/ellipsoid intersection check masks the far hemisphere even when Google's globe primitive is hidden. Real Cesium entity/math tests verify signed/zero coordinates, updated retained IDs, depth settings, heading changes, far-side rejection and restoration after camera movement. The one-metre intersection tolerance is numerical rendering tolerance, not a claimed source uncertainty radius.

Live tracks use source observation clocks where supplied; receipt-only positions retain an explicit observation-time-unknown label. Aircraft/vessels expire after 120/600 seconds. Source-stale or aging observations within those limits remain visibly last known by default: muted hollow symbols, LAST KNOWN labels and explicit detail clocks. A layer control hides these bounded last-known live observations when desired. Freshness stays at 45 seconds for aircraft and 120 seconds for vessels, with the provider stale flag taking precedence. Replay symbols are labeled RECORDED. Fetching or rendering an old observation never makes it fresh, and no position is extrapolated. Replay requests six-hour snapshot slices around the cursor, instead of sending a months-long report domain to an API with a bounded window. Capture time remains distinct from observation time, and old snapshots expire against replay time. Current thermal observations cannot appear before their acquisition time in replay. Inherited infrastructure/routes are optional, off by default and explicitly unverified; schematic routes do not claim surveyed geometry or current operating status.

The local analysis/video tools are exposed through Brief/Media. Their component tests cover explicit authenticated generation, bounded source IDs, unreviewed/stale labels, sanitized source links, content-addressed video paths and serial cancellable refresh. The operator key is optional React memory state and is never delivered in public configuration, browser storage or URLs. Actual generation/model/media qualification is recorded by the backend/integration workflow.

## Cesium compatibility repair

Windows Playwright WebKit exposes native WebGL2 but lacks `OffscreenCanvas`. The installed Cesium 1.139.1 Material implementation used two unguarded `instanceof OffscreenCanvas` expressions, causing a genuine constructor/material failure. `skyBox:false` avoids constructing unused Sun/Moon materials, and `tools/patch-cesium.mjs` narrowly guards those checks in the engine source and both shipped bundles. The script validates original/patched SHA-256 and exact versions before changing files. It runs after normal npm installation and explicitly after Docker's `npm ci --ignore-scripts`. No browser API or renderer capability is fabricated. Native WebKit ColorMaterial construction passed with `typeof OffscreenCanvas === "undefined"`.

The [upstream Material source](https://github.com/CesiumGS/cesium/blob/1.139/packages/engine/Source/Scene/Material.js), [Cesium Cartesian coordinate contract](https://cesium.com/learn/cesiumjs/ref-doc/Cartesian3.html#fromDegrees), [height-reference semantics](https://cesium.com/learn/cesiumjs/ref-doc/HeightReference.html) and [terrain-depth contract](https://cesium.com/learn/cesiumjs/ref-doc/Globe.html#depthTestAgainstTerrain) informed the repair. Original Apache-2.0 notices are unchanged. An upgrade with unknown source bytes fails closed and requires review.
