No World Monitor, God's Eye View, OpenCTI or Bellingcat implementation was copied into this candidate. Those projects informed research and design decisions documented with primary sources in `docs/CURRENT_RESEARCH.md`.

Runtime packages retain their own licenses, including Cesium (Apache-2.0), Leaflet (BSD-2-Clause), React (MIT), Three.js (MIT), satellite.js (MIT), DOMPurify (Apache-2.0 or MPL-2.0), FastAPI (MIT), SQLAlchemy (MIT), Telethon (MIT), and PostGIS (GPL-2.0-or-later). This list is a summary; the resolved package distributions and lockfiles are authoritative for package versions and individual notices. Docker images and installed dependency binaries are not vendored in the source ZIP. The PostGIS source patch described below is included.

The upstream-derived [FlatGeobuf patch](tools/postgis/flatgeobuf-3.6.4.patch) remains **GPL-2.0-or-later**, outside the MIT application-code grant. The original patch credits Darafei Praliaskouski and retains its upstream attribution. It comes from the official PostGIS stable-3.6 [merge `767fa406`](https://github.com/postgis/postgis/commit/767fa40644253281f6d4e8b06811489b0a0f9b0d), whose patch-bearing parent is [`53e273fa`](https://github.com/postgis/postgis/commit/53e273faeb440176eee83f76319b48afb0b86834). Two local contexts preserve released 3.6.4 behavior: the unsigned-32-bit Datum conversion and widening a decoded float to a PostgreSQL double-precision target. The validation changes and regression cases are retained; the development-branch NEWS entry is excluded when applying the patch. The applied patch SHA-256 is `7dc9dec77d21562088a1574a27f9f91d8604a4c4d6055e6d63bc0be226b75632`. The [full license text](docs/licenses/PostGIS-COPYING.txt) is the original `COPYING` from the pinned official PostGIS 3.6.4 archive, preserved byte-for-byte (SHA-256 `8177f97513213526df2cf6184d8ff986c675afb514d4e68a404010521b880643`). The [build recipe](tools/postgis/build_postgis.sh) verifies both the upstream and adapted patch hashes and retains both patches as provenance in the built image.

The bundled boundary/coastline vectors are exact Natural Earth v5.1.2 source bytes (public-domain vector terms). The night texture is the original NASA 2016 Black Marble image under the documented NASA media-use permission and required credit. These assets are not relicensed as MIT or presented as current imagery. See `docs/ASSET_PROVENANCE.md` and `frontend/public/textures/asset-manifest.json` for exact URLs, hashes, usage terms and limitations.

Google Maps/Photorealistic 3D Tiles, Esri imagery, OpenStreetMap-derived maps, adsb.lol, AISStream, CelesTrak, NASA FIRMS, Yahoo Finance, external media and individual publishers impose their own terms. Preserve provider attribution in the rendered view. A public API or free key does not authorize arbitrary caching or redistribution. Google attribution and tile copyrights remain visible through Cesium's credit display.

ACLED data and World Monitor hosted outputs are excluded from the release. Optional adapters or dataset exports require a separate rights review. The synthetic exercise is authored test data; its labels explicitly distinguish it from observed intelligence.

The optional local speech worker, `backend/app/workers/piper_speech.py`, is explicitly GPL-3.0-or-later. Its corresponding source is included, and the full license is preserved in `docs/licenses/PIPER_GPL_3.txt`. The service invokes it through a separate process and files. Exact source links, voice hashes, model digests and the limited evaluation are documented in [local AI/video](docs/LOCAL_AI_VIDEO.md).

The restricted [media build recipe](backend/container/build_ffmpeg.sh) selects **FFmpeg 9.0.2 with GPL-2.0-or-later licensing** through `--enable-gpl --enable-libx264`; it does not select `--enable-version3` or `--enable-nonfree`. This is the GPL build described by FFmpeg's original `LICENSE.md` and [official licensing documentation](https://ffmpeg.org/legal.html), rather than the default LGPL-only configuration. The recipe retains the original verified source archive, RSA signature, signer key, license texts and build configuration under `/usr/local/share/ffmpeg/` in the built image. The separately linked Debian `libx264-164` package retains its copyright and source information under `/usr/share/doc/libx264-164/`. The source ZIP distributes the build recipe and notices, without FFmpeg/x264 binaries or their full source archives. Distribution of a built image has separate corresponding-source and notice obligations; this source notice does not certify that broader distribution scope. See the [restricted media build](backend/container/README.md) for the exact component and execution boundaries.

CesiumJS 1.139.1 / engine 23.0.1 has a reproducible, hash-bound compatibility patch guarding two `OffscreenCanvas` checks when that browser global is absent. The original Apache-2.0 notices are preserved. `frontend/tools/patch-cesium.mjs` records original/patched hashes and the upstream source and rejects unreviewed versions or bytes. Historical Leaflet/Three.js/Resium/satellite components remain reference source outside the active compilation graph; their former runtime dependencies are removed from the Earth application.
