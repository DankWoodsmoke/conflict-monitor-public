Runtime packages retain their own licenses, including Cesium (Apache-2.0), Leaflet (BSD-2-Clause), React (MIT), Three.js (MIT), satellite.js (MIT), DOMPurify (Apache-2.0 or MPL-2.0), FastAPI (MIT), SQLAlchemy (MIT), Telethon (MIT), and PostGIS (GPL-2.0-or-later). This list is a summary; the resolved package distributions and lockfiles are authoritative for package versions and individual notices. Docker images and installed dependency binaries are not vendored in the source ZIP. The PostGIS source patch described below is included.

The original patch credits Darafei Praliaskouski and retains its upstream attribution. It comes from the official PostGIS stable-3.6 [merge `767fa406`](https://github.com/postgis/postgis/commit/767fa40644253281f6d4e8b06811489b0a0f9b0d), whose patch-bearing parent is [`53e273fa`](https://github.com/postgis/postgis/commit/53e273faeb440176eee83f76319b48afb0b86834). Two local contexts preserve released 3.6.4 behavior: the unsigned-32-bit Datum conversion and widening a decoded float to a PostgreSQL double-precision target. The validation changes and regression cases are retained; the development-branch NEWS entry is excluded when applying the patch. The applied patch SHA-256 is `7dc9dec77d21562088a1574a27f9f91d8604a4c4d6055e6d63bc0be226b75632`. The [full license text](docs/licenses/PostGIS-COPYING.txt) is the original `COPYING` from the pinned official PostGIS 3.6.4 archive, preserved byte-for-byte (SHA-256 `8177f97513213526df2cf6184d8ff986c675afb514d4e68a404010521b880643`). The [build recipe](tools/postgis/build_postgis.sh) verifies both the upstream and adapted patch hashes and retains both patches as provenance in the built image.
