# Current research and adoption decisions

Initial survey checked **2026-10-28 America/Chicago**. The **October 29 follow-up** below records the subsequent executed local-model comparison and Earth consolidation. This is a scoped comparison of relevant primary sources, not an exhaustive census of all OSINT projects. Repository activity, documentation, software licenses, data rights, and measured application quality are different evidence. No external platform code was copied into this release candidate.

## October 29 executed follow-up

The subsequent [source review](SOURCE_REVIEW.md) measured34 native publisher and
author feeds and admitted31 to a bounded no-model watchlist. Four concurrent
fetches, per-source quotas, durable identity recovery and backoff were exercised
through the actual PostgreSQL/API/WebSocket process, rather than inferred from
HTTP status. The native-feed route avoids depending on paid social APIs or an
unmaintained public scraping bridge. Mastodon/Bluesky/ReliefWeb/push discovery
remain separately reviewed candidates, not implemented connectors. Alignment,
request latency, factual accuracy, first publication and original-source
independence remain distinct. No calibrated source leaderboard was manufactured.

Database research also changed the deployed image and permission boundary:
PostgreSQL17.11/PostGIS3.6.4 replaces the old17.5/3.5.2 profile through an exact
logical restore into a new volume, with fresh collation indexes and a separate
non-owning runtime login. See [upgrade](DB_UPGRADE.md), [container OS review](OS_SECURITY_REVIEW.md)
and [software inventories](qualification/software-inventory/README.md). Package
and vendor backport reviews retain unresolved findings. Their dated results do
not establish a vulnerability-free application or host.

The owner chose one persistent Earth workspace. The actual renderer defects were stale retained entities, invented altitude defaults, disabled depth tests and distorted orbital heights. The new renderer refreshes retained source positions, uses explicit surface projections and independent WGS84 horizon tests, and removes active orbital/cosmetic sensor-like rendering. [Cesium's coordinate contract](https://cesium.com/learn/cesiumjs/ref-doc/Cartesian3.html#fromDegrees), [height references](https://cesium.com/learn/cesiumjs/ref-doc/HeightReference.html) and [terrain depth testing](https://cesium.com/learn/cesiumjs/ref-doc/Globe.html#depthTestAgainstTerrain) informed this repair. Actual Windows WebKit execution also exposed unguarded `OffscreenCanvas` checks in the [upstream Material implementation](https://github.com/CesiumGS/cesium/blob/1.139/packages/engine/Source/Scene/Material.js); the narrow installed-source/bundle patch is version/hash bound and fails on unreviewed bytes. Upgrading alone did not resolve the inspected checks.

The aircraft provider's [published OpenAPI schema](https://api.adsb.lol/api/openapi.json) limits circle radius to 250 NM. Four named regional circles now rotate at the previous one-request/15-second recurring budget; last-good regional observations merge by actual source time, with per-region failure/age and no global-coverage claim. [GDELT's geographic documentation](https://blog.gdeltproject.org/gdelt-geo-2-0-api-debuts/) explicitly describes place mentions and ambiguity; it is not a substitute for verified incident coordinates and was not adopted as an automatic point generator.

The frozen 12-case local-model sample compared stock Qwen3 0.6B, Qwen3 8B and [Qwen3.5 4B](https://ollama.com/library/qwen3.5:4b) using CPU-only inference through [Ollama structured outputs](https://docs.ollama.com/capabilities/structured-outputs). The 4B candidate achieved 11/12 topic labels and 11/12 linguistic-stance labels in this small sample, with one of three batches rejected for a nonliteral mention. It was faster and scored better than the compared cached 8B. These results justify only the optional, unreviewed extraction role: original text remains exact, invalid batches do not publish, and model mentions never assign event coordinates or severity. They do not establish a general model ranking, multilingual factual accuracy or global optimality. Development probes are separate from the frozen evaluation and failed outputs are retained.

Actual source-card video uses a local [Piper engine](https://github.com/OHF-Voice/piper1-gpl), a pinned LJSpeech voice and FFmpeg. The standalone GPL speech worker has explicit notices; model/dataset rights are separate. Narration reads attributed reports over editorial cards, with no generated incident footage. The measured media checks, ASR consistency result and execution limits are in [LOCAL_AI_VIDEO.md](LOCAL_AI_VIDEO.md); final Docker API/database and soak receipts remain the release gate.

## Immediate decisions

1. Recover and preserve the richer April application; improve its contracts rather than replace it with another dashboard.
2. Make synthetic showcase mode explicit, deterministic, keyless and safe to inspect. Never fill a live outage with synthetic records.
3. Separate original reports, event clusters, source lineage, analyst hypotheses and published conclusions. Repetition and source popularity do not establish independent corroboration.
4. Show source observation time, collection time, coverage and failure state. A successful HTTP response, process, or cached panel is not current evidence.
5. Keep source-code licensing separate from data redistribution. Public availability and no-key access are not permission to bundle a dataset.
6. Select any replacement model using held-out multilingual event/attribution/negation tests and measured latency; a general leaderboard is only a candidate filter.

## Evidence design

[W3C PROV](https://www.w3.org/TR/prov-overview/) distinguishes data entities, processing activities and responsible agents. Use the useful minimum: immutable report ID + canonical source ID/URL + original text hash + published/observed/collected timestamps + extraction model/prompt/schema version + evidence span offsets + supersession/correction links. Preserve original bytes where rights and operational scope permit; public exports can retain hashes and permitted excerpts instead of full third-party material.

[STIX 2.1](https://docs.oasis-open.org/cti/stix/v2.1/os/stix-v2.1-os.html) offers external references, opinions, confidence, reports and relationships. Borrow the separation and provide export later; do not force every physical conflict observation into a cyber-indicator object. [STAC](https://stacspec.org/en/about/stac-spec/) is appropriate for imagery assets with footprints, time and links; it is not a confidence model for a news claim. The [Berkeley Protocol project](https://humanrights.berkeley.edu/projects/developing-the-berkeley-protocol-on-digital-open-source-investigations/) supplies a useful collection/preservation/verification/analysis framework; implementing metadata does not certify a forensic investigation.

The original local deduplication implementation conflates report count with independent sources and repeatedly increments a score after three reports. Replace that mechanism with stable original-report IDs, explicit origin lineage and one idempotent cluster calculation. Similarity is a candidate-retrieval feature, not a factual equivalence decision: Arabic/English paraphrases can describe the same incident, while near-identical statements can disagree about actor, victim, date or denial. Keep contradictions and attribution attached to the same case without silently merging them into an asserted fact.

For the GOOL-informed structural lens, preserve three distinct products: **evidence**, **interpretation**, and **hypotheses to test**. A historical analogy or source prior can guide a question but cannot prove today's actor, intent or casualty claim. Require claim-level support, counterevidence, a falsifier, and an explicit unknown when support is absent. Apply that rule symmetrically to all source affiliations and to our own preferred explanation.

## Mapping choices

[MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) is BSD-3-Clause, actively maintained (inspected head `4b6b84185dc6a33494b2820d4bbacf1da72fd49a`, October 27 UTC), supports vector rendering and globe controls. It is a plausible replacement when a measured feature/performance requirement exceeds the recovered Leaflet implementation. Do not rewrite a working map simply because another library is newer.

[PMTiles](https://docs.protomaps.com/pmtiles/) serves a read-only tile archive through HTTP range requests. This can make a reproducible keyless basemap or regional offline pack simpler; it does not replace transactional PostGIS event storage. Basemap data attribution and ODbL remain separate from renderer licensing. Retain Cesium for terrain/3D if that tab passes its own loading and resource-lifecycle tests; lazily load heavy engines and test disposal when changing tabs.

## Release acceptance and remaining evidence

- Test every tab in a deterministic showcase and in explicit no-data/failure states. Check keyboard access, small screens, rendering errors and tab resource cleanup; screenshots alone do not establish behavior.
- Test source outage, malformed payload, old source clock, replayed messages, negation, syndicated copies, conflicting actors, ambiguous place names, and six-digit satellite identifiers.
- Publish a capability matrix that distinguishes synthetic showcase, implemented adapter, locally tested adapter and live-verified integration.
- Keep a source manifest with provider, terms URL, checked date, collection method, attribution, retention/export rights, expected cadence and current health. Recheck at release time.
- Build a clean source export with secret scanning, dependency locks, notices, a license inventory, build/test receipts, and no database dumps, credentials, private GOOL corpus or inherited backup archive.

**Measured satellite change:** `python -m unittest discover -s tests -p test_satellites.py -v` passed 8 tests with no skips. One bounded live OMM fetch returned 45 validated records at 2026-10-29T01:59:59Z. These verify the adapter and its failure regressions; they do not verify all live providers or real-world orbital accuracy. Larger model trials, labeled multilingual quality evaluation, additional imagery/source adapters and comprehensive load testing remain unperformed.

**Implemented SITREP contract:** trusted synthesis instructions are separate from serialized source material; optional inherited Predictive History summaries are explicitly unverified hypotheses with no automatic YouTube fetch. Structured hypotheses require a cited premise, an alternative and a falsifier, or an explicit abstention. Exact schema, citation syntax/membership and complete response checks reject invalid output before persistence. Original bounded report excerpts and hashes are frozen with the generated report. These checks establish source-reference integrity, not semantic entailment or factual truth; output remains unreviewed. Source-network labels no longer add a confirmation bonus to the uncalibrated reporting-activity index, and an empty current observation window is unknown rather than stable. Its revised values are not calibrated against older reports.
