## 2026-10-28 — baseline and boundaries

- The owner selected the April 8 full server backup plus the local working changes as the starting point. The former VPS timed out during a read-only SSH probe; this release does not assert that server state is current.
- Recovered 87 source/assets files into this separate candidate. Original Git index, worktree, archive, database, sessions and environment files remain unchanged. `recovery-manifest.json` records original source hashes, not final release hashes.
- Preserve the fuller April application and its four views. The March local tree is a comparison source, not an automatic overlay that could erase later capabilities.
  Superseded by the owner's October29 instruction to consolidate the capabilities into one persistent Earth workspace; see below.
- Evidence accuracy precedes model replacement. Report count and political-network diversity do not prove independent origins. A thermal anomaly does not identify a strike or its perpetrator. Unknown locations stay unknown.
- Public showcase uses explicit synthetic fixtures. It must work without credentials, paid APIs, a database, or background ingestion. Live operation requires deliberate configuration.
- Preserve the project's analytical identity as labeled hypotheses, alternatives and falsifiers. Do not publish GOOL's private corpus or persona. No automatic model promotion without an evaluation result.
- Research code/data licenses independently. No wholesale AGPL code import into the inherited MIT source; no redistribution of restricted datasets.
- Prepare a sanitized public snapshot independently of the private repository history. Do not change the private repository's visibility.
